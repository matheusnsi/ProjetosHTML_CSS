# 🎨 Projetos HTML, CSS & JavaScript

Coletânea de **30 projetos práticos** de front-end desenvolvidos com HTML, CSS e JavaScript, cobrindo desde layouts responsivos até pequenas interações. Reúne exercícios e mini-projetos que consolidam os fundamentos de desenvolvimento web.

## 🛠️ Tecnologias

- **HTML5**
- **CSS3** (Flexbox, Grid, responsividade)
- **JavaScript**

## 📁 Organização

Cada pasta contém um projeto independente, com seus próprios arquivos HTML, CSS e JS. Basta abrir o `index.html` de cada um no navegador.
